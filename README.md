CRM — Gestão de Clientes e Funcionários

Sistema desenvolvido a partir da evolução de uma versão anterior, atualizado conforme solicitação do cliente. A nova versão busca modernizar a experiência de utilização e ampliar as possibilidades de gestão, permitindo trabalhar não apenas com clientes e oportunidades, mas também com informações relacionadas à equipe/funcionários.

O que vale destacar no README
Front-end: Next.js, React, TypeScript
Back-end: Java + Spring Boot
Banco: PostgreSQL
API: REST
Persistência: JPA/Hibernate
Integração: Front-end consumindo API REST
Deploy: Vercel + Railway
Evolução de sistema existente: nova versão desenvolvida a partir de uma aplicação anterior
Demanda real: atualização solicitada pelo cliente
